Website Site Plan

WDD 231 - Individual Project Site Plan

1. Site Name

Name: JJ Enterprise Web Portal

Reason for Choice: I chose JJ Enterprise because developing a business portal allows me to build a realistic, production-ready website that strictly aligns with the course learning outcomes. It provides an ideal framework to demonstrate structured HTML/CSS best practices, responsive layouts, client-side data parsing using dynamic JSON, and local storage state management for user interactions.

Optional Domain Availability: jjenterprise.com

2. Site Purpose

JJ Enterprise will be a 3-page responsive website designed to showcase company services, product catalogs, and customer resources.

  • Home Page: Overview of JJ Enterprise's mission, featured core services, interactive call-to-action sections, and dynamic customer announcements.
  • Services & Product Catalog Page: A dynamic, filterable catalog built using JSON data that allows users to search, filter by category, and view product details or pricing models seamlessly.
  • Contact & Inquiry Page: An interactive contact page featuring a multi-field inquiry form with client-side validation, integrated location/browser API functionality, and operational business hours.

3. Scenarios

  • Scenario 1: Where can a potential customer view the core services offered by JJ Enterprise and see recent company announcements?
  • Scenario 2: How can a site visitor filter products by category and inspect pricing details directly from dynamic data?
  • Scenario 3: How does a client submit an inquiry form while verifying operational hours and location details?
