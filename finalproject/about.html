About This Project

This final project demonstrates the skills learned in the course: semantic HTML, responsive CSS, and modern JavaScript. It uses a green design system, accessible components, and dynamic data fetched from a local JSON file.

Design Goals

  • Responsive layout that works on small (320px) and large screens.
  • Accessible navigation and modal dialogs.
  • Performance-minded assets and lazy-loading images.
