# Final Project — JJ Enterprise (finalproject)

This branch (finalproject-rewrite) contains a rebuilt, accessible, and professional final project site for the WDD231 assignment.

Files included (in branch `finalproject-rewrite`):

- finalproject/index.html — landing page with featured offerings
- finalproject/catalog.html — dynamic catalog (client-side) with accessible modal details
- finalproject/contact.html — accessible contact form
- finalproject/form-results.html — client-side form results
- finalproject/styles/finalproject.css — stylesheet using a professional deep-blue palette
- finalproject/scripts/main.js — site utilities (nav, year)
- finalproject/scripts/catalog.mjs — catalog rendering, modal, and filters
- finalproject/data/services.json — sample catalog data so the site works out-of-the-box

Preview and publish
- To preview locally, clone the repo and open the files under finalproject/ in a browser.
- To publish on GitHub Pages: merge this branch into main and enable Pages in repository settings (docs/root or branch root). The canonical URL used in the meta tags assumes: https://josephjohn2806.github.io/wdd231/finalproject/

Grader checklist
- [ ] Test in Chrome, Firefox, and mobile emulation
- [ ] DevTools Console: no JavaScript runtime errors
- [ ] Lighthouse (mobile & desktop): Accessibility 90+, Best Practices 90+, SEO 90+
- [ ] CSS Overview: color contrast passes WCAG AA
- [ ] Keyboard navigation: Skip link, nav toggle, modal open/close with keyboard
- [ ] Footer contains a video link (placeholder). Replace with your recorded demo video before submission if desired.
